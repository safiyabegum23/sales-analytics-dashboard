# Sales Analytics Dashboard

## Project Overview

The Sales Analytics Dashboard is a Python-based data analytics project built using Streamlit and Pandas. It helps users analyze sales performance across different cities and products.

## Features

* Total revenue and profit calculations
* Total orders and quantity sold
* Average order value and profit margin
* Revenue analysis by city and product
* Profit analysis by product
* Interactive city and product filters
* Searchable sales records
* Download filtered sales data as a CSV file
* Top-performing city and product identification

## Technologies Used

* Python
* Pandas
* Streamlit
* Matplotlib
* Plotly

## Installation and Setup

### 1. Clone the repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Open the project directory

```bash
cd Sales_Analytics_Project
```

### 3. Install the dependencies

```bash
pip install -r requirements.txt
```

### 4. Run the dashboard

```bash
python -m streamlit run dashboard/app.py
```

## Dataset

The project uses a sample sales dataset containing order IDs, products, cities, quantities, prices, and profits.
